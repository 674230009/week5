# 🍲 ระบบจัดการข้อมูลเมนูอาหารและวัตถุดิบ (Food & Recipe Management System)

ระบบเว็บแอปพลิเคชันสำหรับจัดการข้อมูลเมนูอาหาร หมวดหมู่ รูปภาพ และรายการวัตถุดิบ/ส่วนผสม พัฒนาด้วย **PHP (PDO)** ร่วมกับฐานข้อมูล **MySQL** และตกแต่งหน้าตาด้วย **Bootstrap 5**

---

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

* **Backend Language:** PHP (PDO Extension)
* **Database Management:** MySQL / MariaDB (ชื่อฐานข้อมูล: `food_db`)
* **Frontend Framework:** Bootstrap 5 (ผ่าน CDN), HTML5, CSS3, JavaScript (Vanilla JS)
* **Web Server Environment:** Apache (XAMPP Server)
* **Development Editor:** Visual Studio Code (VS Code)

---

## ✨ ฟีเจอร์หลักของระบบ (Main Features)

1. **📋 หน้าแสดงรายการเมนูอาหาร (`index.php`)**
   * แสดงรายการอาหารทั้งหมด พร้อมรูปภาพ หมวดหมู่ และรายการวัตถุดิบพร้อมจำนวน/หน่วยนับ
   * มีปุ่มสำหรับ **เพิ่มเมนูใหม่**, **แก้ไข**, และ **ลบ** เมนูอาหาร
   * ระบบตรวจสอบและแสดงผลรูปภาพภาษาไทย รองรับระบบปฏิบัติการ Windows

2. **✏️ หน้าเพิ่มและแก้ไขข้อมูล (`manage.php`)**
   * ฟอร์มกรอกชื่ออาหารภาษาไทย และเลือกหมวดหมู่อาหาร (อาหารตามสั่ง, อาหารคาว, อาหารหวาน, เครื่องดื่ม)
   * เลือกรูปภาพประจำเมนูจากโฟลเดอร์ `images/`
   * เพิ่ม/ลด รายการวัตถุดิบ จำนวน และหน่วยนับได้หลายรายการแบบ Dynamic Form

3. **🔄 สคริปต์ซิงค์รูปภาพอัตโนมัติ (`sync_images.php`)**
   * ตรวจสอบไฟล์รูปภาพในโฟลเดอร์ `images/` และจับคู่กับชื่อเมนูอาหารในฐานข้อมูลโดยอัตโนมัติ

---

## 🗄️ โครงสร้างฐานข้อมูล (Database Schema)

* **ชื่อฐานข้อมูล:** `food_db`
* **ตาราง `foods`**: เก็บข้อมูลเมนูหลัก (`id`, `name_th`, `category`, `image_name`)
* **ตาราง `recipes`**: เก็บรายการวัตถุดิบ (`id`, `food_id`, `recipe_name`, `quantity`, `unit_name`)
